# The Vault — Card Collector (basis)

Een eerste lokale basis voor een persoonlijke One Piece TCG + Magic: The Gathering collectie.

## Starten

1. Pak de ZIP uit.
2. Open `index.html` in Chrome, Edge, Firefox of Safari.
3. Klaar.

Er is geen server nodig.

## Wat werkt al

- Dashboard met totaal aantal kaarten en geschatte waarde.
- Scheiding One Piece TCG / Magic: The Gathering.
- Digitale binder / collectie-overzicht.
- Zoeken.
- Filteren op game en rarity.
- Kaarten toevoegen.
- Aantal, conditie, foil en waarde opslaan.
- Afbeelding via URL.
- Kaarten verwijderen.
- Opslag via `localStorage`, dus je collectie blijft in dezelfde browser bewaard.

## Volgende logische stap

Migreren naar Laravel + MySQL en kaartdata automatisch ophalen via externe API's.
